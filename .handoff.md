## Confirmed product decisions

### Project and tracks
- Separate editable Keysound project, entered through the start menu's Keysounding panel. Save/Ctrl+S saves project data; Generate creates playable output.
- No arbitrary instrument-track count limit. Selected track is editable; optional faint, uneditable ghost notes show other tracks.
- Optional vertical gameplay-object markers. Drawing exactly on one still requires explicit Sync.
- Lightweight, small-download bundled piano; new tracks load it by default. Specific piano/licensing still need research.
- Windows x64 VST3 instruments, native windows and saved state. One preset per track; sustain, pitch bend and modulation supported. VST2, 32-bit, insert effects and arbitrary parameter automation deferred.
- VST crash affects only that instrument; other tracks continue, project stays editable, offer reload from last saved state. Host architecture is not yet selected/proven.
- Missing VST: retain state, keep track silent and editable, offer locate/replace, never silently substitute piano. Block Generate only if that instrument is required.
- Instrument replacement and track deletion are each one undo step restoring previous state; replacement leaves notes/controllers unchanged.
- Mute/solo are playback-only. Separate Include in Generate switch, enabled for new/imported tracks; clearly mark excluded tracks.

### Timing and import
- Reference beatmap red lines govern timing. MIDI import preserves musical beat positions, not elapsed time; bar numbers align only if meter/origin align.
- Import tracks separately with names. Preview placement and instrument choices, piano default, percussion flagged. Default first-beat placement is first red timing point; adjustable before import.
- MIDI-only projects initially use MIDI tempo map; preview adoption of a later reference's red lines.
- Audio-only projects allow manual BPM, meter and beat-one offset; automatic tempo detection deferred.
- Tempo changes preserve note/controller beat positions. Song audio is neither stretched nor shifted.

### Recording
- Physical MIDI audition and ordinary replacement recording; loop recording deferred.
- Replace notes whose starts lie within the recorded range on the armed track. Notes starting before the range remain intact even if overlapping; later notes preserved.
- Replace sustain/pitch-bend/modulation events in range. Restore the original controller state at the end boundary for untouched later music.
- Preserve played timing; quantize explicitly afterward. Toggleable metronome/count-in, one-bar count-in enabled by default.
- Stop ends held recorded notes at the stop point; natural release tails remain audible.
- Entire recording pass, including controller replacement/restoration, is one undo step.

### Sync
- Explicit preview/apply action; selected notes or all tracks included in Generate. Default maximum shift 20 ms, adjustable, with target-type filters.
- Eligible targets: circles, slider heads/repeats/tails and spinner ends. No new gameplay objects.
- Preserve valid assignments during bulk Sync by default; explicit re-sync-all option.
- Equally close targets require manual choice in preview, showing times/types; unresolved notes remain unsynced.
- Changing note start clears assignment. Pitch/velocity/length edits retain it. Moved/missing reference targets are flagged, never silently retargeted.
- Applying Sync is one undo step across tracks, restoring times and assignments.

### Save and Generate
- Copy reference beatmap, song audio and referenced visual assets into project. Keep reference snapshot until explicit update, previewing affected assignments.
- Render each synced note occurrence independently to WAV with dynamics, controllers, duration and release tail. Reuse only identical resulting audio; no per-note normalization. Native sound combinations first, mix only otherwise.
- Generated [Keysounds] replaces original hitsounds only in generated copy; source map untouched. Keysounds layer over existing song.
- Preview skipped unsynced counts per track, allow continue or return to fix.
- Separate output folder inside project; offer Export .osz after success and retain folder.
- Preserve background/video/visual storyboard and required assets; remove storyboard sound events from output. Missing visuals warn; missing song audio blocks export.
- Missing/failing required instrument stops generation and identifies track. Cancellation/failure preserves previous successful output; stage new output separately and replace only after success.
