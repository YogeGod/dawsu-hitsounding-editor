This is a hitsound editor which is heavily based on Cubase'S MIDI drum editor. I have been using it for over a decade and find that it practically does everything you could ask for when it comes to programming drums/percussion. This editor lets you hitsound your maps super efficiently and much more easily. It can often take hours to hitsound an entire map when using the osu! editor, with this app you can get it done in under 20 minutes.
