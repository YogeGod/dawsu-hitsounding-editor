# dawsu! hitsound studio 1.1

- Added a remembered HS difficulty toggle for initially empty difficulties and difficulties named HS or hitsounds.
- Enabling HS mode backfills existing loose hitsounds with centred circles in one undoable action. Shared timestamps use one circle; removing its last sound removes the generated circle.
- Turning HS mode off keeps generated circles. Turning it back on resumes maintenance. Pre-existing gameplay objects remain protected.
- Normal Save writes HS objects into the current difficulty and offers the existing mixing controls when layers require a mix.
- Fixed volume changes when moving, copying or pasting sounds onto an occupied circle. Individual layer volumes now survive mixing, undo/redo and Save/reload, including overlapping copies of the same sample.
- HS Save now warns before writing slider body or tick sound changes and retains the warning in the save status. Cancelling leaves the map unchanged.
- Includes fixes for sample replacement, Revert state and copying simultaneous hitsounds.

Windows x64 portable: extract the ZIP and run `OsuHitsoundEditor.exe`. No separate .NET installation is needed. Keep the included DLLs beside the EXE.

Verification includes unit tests, the map corpus, headless UI workflows and rendered audio-data comparisons. Physical playback and ASIO hardware were not tested.
