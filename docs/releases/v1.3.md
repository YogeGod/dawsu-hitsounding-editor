# dawsu! hitsound studio v1.3

- Added Cubase-style Drum-map view: a flat, freely ordered instrument list over the existing hitsound lanes. Switch using the keyboard button beside the lane header controls; right-click it for Drum Map Setup.
- Included Yoge Expanded Kit and Yoge Simple Kit. Both start unassigned so you can choose their samples.
- Create, duplicate, rename and share mapset-wide drum presets, with portable `.dawsudrum` files that can include actual sample audio. Loading offers preset samples or your own samples; missing numbered samples use the family default.
- Create extra numbered layers directly in Setup and assign them freely to instruments. Aliases mirror the same underlying hits without duplicating edits or playback.
- Restored Electron V6.39's immediate **+** behavior: new numbered lanes start empty with the bundled family sound. Existing samples and other difficulties remain protected.
- Added explicit current-difficulty reassignment/migration with overlap choices and Undo. Fixed Undo of newly added lanes in Drum-map view.
- Polished the entire dark editor: consistent controls/dialogs, clearer text and tool icons, better sidebar/form alignment and scrollable compact toolbars.
- Includes hitsounds-only Generate by default with optional slider-body/tick audio, reusable sound sets with portable audio, long 2/1–4/1 snapping and role-preserving hitsound pairing from the feature branch.

**Windows x64 portable:** extract the entire ZIP and run `OsuHitsoundEditor.exe`. No separate .NET installation is required. Keep the included files together. Version: **1.3.0**.

Validation: **598 tests passed**, including compiler/decompiler, editing and map-corpus coverage, plus **164 headless interaction/workflow checks**. Native package startup is checked separately. Physical audio playback, ASIO hardware and live osu! gameplay were not manually verified. Checksums are included in `SHA256SUMS.txt`.
