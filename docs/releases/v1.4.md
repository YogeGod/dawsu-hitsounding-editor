# dawsu! hitsound studio V1.4

- Closing unsaved work now offers **Save / Discard / Cancel**. Failed or cancelled saves keep the editor open; discarded loose hits do not return through project autosave.
- **Ctrl+S** and **F1** work while a text field is focused, while normal typing and text-editing shortcuts stay in the field.
- The sample browser names the active lane and explains whole-lane replacement, with separate assignment and preview actions.
- The always-visible volume control explains that sounds at the selected gameplay times share volume across lanes.
- **Next problem** selects and reveals conflicts or hits without gameplay objects. **What gets saved** explains selected hits, with raw osu! fields under Advanced.
- Compact windows retain usable timeline space through Grid, View, Song and Playback popovers. Active-lane controls, Copy hitsounds scope, output details and keyboard navigation are clearer.

**Windows x64 portable:** extract the entire ZIP and run `OsuHitsoundEditor.exe`. No separate .NET installation is required. Keep all extracted files together. Version: **1.4.0**.

The release includes the completed workflow improvements. The separate layout/icon cleanup and larger-diamond work are not included.
