# dawsu! V1.5

- Choose **Preferences → General → File browser**: **Classic** inside the inspector or the **Folder tree** sidebar. The choice applies immediately and is remembered across restarts.
- Opening a beatmap edits that file directly, without automatically creating a duplicate mapset folder. Save-time backups remain.
- The file browser is on the left. The empty first-click Recent projects menu is fixed.
- Start screen with Open, Recent projects and sample auditioning, with scrolling and visible open/import errors.
- Flat sample lanes: no sample-set folders. Drag lane families across Normal, Soft and Drum; ordering survives reopening and Undo/Redo.
- Select multiple lanes with Shift/Ctrl and apply mute/solo to the selection as a group.
- Prefer exact native osu! sample combinations before mixing audio, including Save, Generate and Copy.
- Right-side sample browser with expandable folders, drag-and-drop replacement and Add to selected lane.
- Grab tool, optional panels, editor-only bookmark labels and All lanes / Selected lanes volume scope. Enter applies a typed volume.
- Refined spacing, icons and larger hit diamonds.

**Windows x64 portable:** extract the entire ZIP and run `OsuHitsoundEditor.exe`. No separate .NET installation is needed. Keep all extracted files together. Version: **1.5.0**.
