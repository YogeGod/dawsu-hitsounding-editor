# dawsu! V2.0.1

A small fix to V2.0's resizable lane list.

## Fixes
- Dragging the lane list's edge now only grabs the list side of the edge. Clicks at the very start of the grid, on the ruler and on the list's ‹ button work again.
- Dragging the lane list wider or narrower is smoother: only the lanes and the controls lined up with them update while you drag.
- Your lane-list width is kept in your own preferences. Double-click the edge to go back to the default width.

**Windows x64 portable:** extract the entire ZIP and run `OsuHitsoundEditor.exe`. Keep all extracted files together. No separate .NET installation is needed. Version: **2.0.1**.
