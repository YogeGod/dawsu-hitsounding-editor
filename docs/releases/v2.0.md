# dawsu! V2.0

## Keysound mode (new)
- A second editor for keysounding: tracks of MIDI notes in a Cubase-style key editor, with the bundled piano or a **VST3 instrument per track**. Each plug-in runs in its own process, so a crash shows **Crashed / Reload** instead of closing the app.
- Import MIDI, play and record from a MIDI keyboard, and edit with key-editor gestures.
- **Sync** notes to the map's gameplay objects, then **Generate** a `[Keysounds]` difficulty: every note is rendered to a WAV and placed on its object. **Export .osz** packs the result.

## Hitsound editor
- New look carried over from the Figma design: shared colours, buttons and icons, and its own window title bar.
- Cubase-style editing: grey snap lines, hits and volume bars coloured by volume (blue to red), relative multi-bar volume drags (Ctrl+drag spreads them), a cycle range you can move and resize in the ruler, Cubase arrow keys, and an editable Start box.
- Gameplay objects drawn over the waveform with osu!'s classic skin textures, combo numbers and colours, in a strip whose height you can drag. Double-click an object to move the playhead there and hear it.
- **Only lanes with hits** view toggle. The waveform shows transients in full colour and the rest dimmed.
- **Change what a slider's body plays:** right-click a slider in the object strip for its slide sample set (also the ticks), slide additions (the whistle) and Whistle on slide, as osu!'s editor sets them on a whole slider.
- Live **Drums VST** playback with MIDI mapping and WAV export.

## Fixes
- **Save .osu no longer creates hidden copies of hitnormals.** Adding a sound from another sample index now moves the whole object to that index, as osu!'s editor does, and Save writes the index with green lines. Keeping mixed indexes on one object is an option (File → Export settings), and Save names any combined files before writing them.
- A green line within 5 ms after an object is now the one that gets changed, instead of a new line osu! would ignore.
- Space, box select and drawing in the hitsound editor; editor shortcuts now win over focused controls, including in flyouts.

**Windows x64 portable:** extract the entire ZIP and run `OsuHitsoundEditor.exe`. No separate .NET installation is needed. Keep all extracted files together. Version: **2.0.0**.
