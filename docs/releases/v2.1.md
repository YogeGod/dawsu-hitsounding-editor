# dawsu! V2.1

## Install and update
- dawsu! now comes as an installer, `dawsu-win-Setup.exe`. It installs for your Windows user without administrator rights and adds dawsu! to the Start menu.
- Running a newer installer updates the existing install in place and keeps your settings. **File → Check for updates…** does the same from inside the app, and the app quietly checks once a day.
- The app is now `dawsu!.exe` and has its own dawsu! icon.
- V2.0 and earlier were unzipped folders. The installer can't find those, so remove the old folder yourself once dawsu! is installed. Your settings carry over.

## Choose your controls
- On first launch, dawsu! asks whether you want **DAW-like keys** or **osu! editor controls**. You can switch at any time in Preferences → Keys.
- With osu! editor controls, both editors work like osu!'s editor:
  - The mouse wheel and the arrow keys move the playhead along the grid. Hold Shift for four steps.
  - Ctrl+wheel changes the snap, and Alt+wheel zooms.
  - Z and V jump to the first and last object. X and C play and pause.
  - 1 selects and 2 places.

## Keysound editor
- It now looks and works like the Hitsound editor: the same icon toolbar with the locators, the same compact selection bar (collapsing it collapses both), the same bottom bar, and themes.
- **Musical typing (Alt+K):** play the selected track from your computer keyboard.
  - The A row plays the white keys and the row above plays the black keys.
  - Z and X change the octave, and C and V change the velocity.
  - It records like a MIDI keyboard.
  - While it's open, the editor's other shortcuts are off, except Space (play/stop) and Esc (close).
- Double-click a note to select it, move the playhead there and hear it, as in the Hitsound editor. Alt+wheel changes the snap.

## Everywhere
- The house button next to the dawsu! name, or **File → Start screen**, goes back to the start screen. It asks to save first.

**Windows x64:** run `dawsu-win-Setup.exe`, or extract `dawsu-win-Portable.zip` and run `dawsu!.exe`. Version: **2.1.0**.
