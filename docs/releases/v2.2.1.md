# dawsu! V2.2.1

Fixes for three problems found by checking dawsu!'s saved mapsets with Mapset Verifier.

## Fixes
- **Older slider lines:** some older maps have slider lines that stop early. Adding edge hitsounds to one of those now writes the whole line, as osu! does. Before, Mapset Verifier couldn't open the mapset after a Save or Copy. The sliders sound the same as before.
- **Silent sounds:** a silent sound that dawsu! writes is now the 44-byte blank.wav. That is the only silent hitsound file the ranking criteria allow. Before, it was a short silent WAV, which Mapset Verifier reports as a Problem.
- **Empty sample files:** a sample file that holds no audio, such as an empty .ogg used to mute a sound, now counts as silence. Before, Save failed with "could not be decoded" once a combined sample used it.

**Windows x64:** run `dawsu-win-Setup.exe`. It updates an existing install in place, or dawsu! finds the update itself under **File → Check for updates…**. Or extract `dawsu-win-Portable.zip` and run `dawsu!.exe`. Version: **2.2.1**.
