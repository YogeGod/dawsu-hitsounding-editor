# dawsu! V2.2.2

## Drum lanes from your drum VST
- **Map lanes from drum instrument:** dawsu! can make your drum map from the drum plug-in's own mapping. It runs when you load a drum VST3, or from **Playback → Map lanes from drum instrument…**, Drum Map Setup and the Drums VST window.
  - Each drum and articulation gets a named lane with its own drum sample index and MIDI note. Hits are named after their drum (Kick, Snare, Rack Tom 1), and other articulations keep their own name (Flam, Sidestick, Open 1). Chokes are left out unless you tick **Include chokes**.
  - If your drum map has unassigned rows (such as the starter kit's), they're filled and keep their names: T1 gets Rack Tom 1, Tight Tip gets Tip Tight, Right Crash gets Main Crash R. Rows the kit has nothing for stay unassigned. Otherwise a new drum map named after the plug-in is added.
  - By default the lanes play through the VST3, with each hit's volume as its velocity. Use **Render drums…** to bake them into WAVs for Save. You can also give each lane a one-shot sample of the kit (one velocity).
- **Kontakt and other plug-ins that don't say what their notes are:** dawsu! waits until a kit is loaded in the plug-in, then asks which mapping to use. For GGD libraries, click **EXPORT MAP** on the library's Mappings page once: dawsu! lists those exports from your Documents folder, newest first. You can also choose a built-in kit or browse for a map file.
- dawsu! knows GGD Matt Garstka Signature Drums' default mapping and reads note names from plug-ins that report them.

## Changes
- **Type to jump in lists:** in dialog lists such as the VST3 chooser, typing a letter jumps to the next entry that starts with it (K → Kontakt, K again → Kontakt 7). Typing quickly matches more of the name.
- **Update from the start screen or the editor:** the start screen has a **Check for updates** link next to the version. When a new version is found, the link changes to **Update to …**, and an update button appears in the editor's top bar. Clicking either one downloads the update, asks about unsaved work, then installs and restarts dawsu!. **File → Check for updates…** works the same way.
- **Bookmark labels on the timeline:** a bookmark's label now shows next to its flag on the ruler, not only when you hover the flag. Bar numbers under a label are hidden, and a label that runs into the next flag ends with "…". Bookmarks without a label stay plain flags. You can name a bookmark in the Bookmarks card.
- **Long map names:** a long map name no longer puts a scrollbar over the top bar. The name now ends with "…" when it doesn't fit.

**Windows x64:** run `dawsu-win-Setup.exe`. It updates an existing install in place, or dawsu! finds the update itself under **File → Check for updates…**. Or extract `dawsu-win-Portable.zip` and run `dawsu!.exe`. Version: **2.2.2**.
