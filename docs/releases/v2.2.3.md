# dawsu! V2.2.3

## Open the map osu! has open, and stay in step with it
- **Open map from osu!:** in **File → Open map from osu!**, or the link at the bottom of the start screen. It opens the map osu!'s editor has open:
  - **un!stable:** dawsu! asks it directly, over the same connection Mapping Tools uses.
  - **osu!stable:** dawsu! reads the open map from osu!.
  - **osu!lazer:** use **File → Edit externally** in lazer's editor first, then open the map from that folder.
- **Live reload:** when you save the map in osu!'s editor, dawsu! reloads it straight away. You don't have to reopen it.
  - You keep your place: zoom, scroll, playhead and lane layout stay as they were.
  - Your unsaved hitsound edits stay too: hits, volumes and layer volumes. Hitsounds you changed in osu! are kept as well.
  - A hit whose object you deleted in osu! stays, with no object, so nothing disappears silently.
  - If you also have unsaved slide, sound-set or bookmark edits, dawsu! asks before reloading.
- **osu! reloads after you save in dawsu!:** when osu!'s editor has the same map open, it reloads it, so it shows your new hitsounds. Anything unsaved in osu!'s editor is lost when it reloads. Switch this off under **File → Reload osu!'s editor after Save**.

**Windows x64:** run `dawsu-win-Setup.exe`. It updates an existing install in place, or dawsu! finds the update itself under **File → Check for updates…**. Or extract `dawsu-win-Portable.zip` and run `dawsu!.exe`. Version: **2.2.3**.
