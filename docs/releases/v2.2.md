# dawsu! V2.2

## SoundFont (.sf2) instruments
- **Keysound mode:** choose **Instrument… → SoundFont (.sf2)…** for a track, then pick one of the file's presets.
  - The track plays it in playback, in auditions, from a MIDI keyboard and with musical typing.
  - **Generate** renders the keysounds with the same preset.
  - **Preset…** switches to another preset in the file.
  - **Reverb and chorus** turns the SoundFont's own effects off for dry keysounds.
  - A SoundFont that has moved shows as missing, with **Locate…** to find it again.
- **Hitsound mode:** the drum instrument window takes a **SoundFont kit** as well as a VST3. It plays mapped drum lanes live and renders them to drum WAVs. Drum-kit presets are listed first.
- Projects remember where the .sf2 is rather than copying it. dawsu! only opens SoundFonts stored on this computer.

**Windows x64:** run `dawsu-win-Setup.exe`. It updates an existing V2.1 install in place, or V2.1 finds the update itself under **File → Check for updates…**. Or extract `dawsu-win-Portable.zip` and run `dawsu!.exe`. Version: **2.2.0**.
